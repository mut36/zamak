# 실험 로그

하네스(`npm run harness`)로 돌린 실험을 시간순으로 쌓는다. 결정으로 이어졌든 아니든
전부 적는다 — `.harness/`는 `.gitignore`돼 있어 로컬에서 사라지므로, 여기가 유일하게
남는 기록이다. 결정으로 이어진 항목은 "비고" 열에 `decisions.md` 절 번호를 남긴다.

새 실험을 추가할 땐 표에 한 줄만 보태면 된다 — 별도 형식·승인 필요 없음.

비용(달러)은 실행 시점 하네스 단가로 찍히므로, 단가가 바뀐 뒤(`gemini-limits.md` §4)
비교하려면 표에 있는 원시 토큰 수(`.harness/<타임스탬프>/summary.md`가 아직 로컬에
남아있다면 거기)를 다시 계산할 것 — 여기 표에는 달러 대신 정렬실패율·오염 건수처럼
가격 변동에 안 흔들리는 값만 남긴다.
