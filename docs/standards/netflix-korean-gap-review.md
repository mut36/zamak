# Netflix 한국어 가이드 ↔ ZAMAK 갭 검토

기준: [`netflix-korean-subtitles.md`](netflix-korean-subtitles.md) (I.1–I.21).  
검토 대상: 프롬프트·후처리·타이밍·글로사리·설정 상수. **코드/프롬프트는 이 문서로
바꾸지 않는다** — 참조·감사용.

기준 시점: 2026-07-28.

## 판정 범례

| 판정 | 의미 |
|---|---|
| **준수** | 프롬프트·코드·설정에 의도적으로 반영됨 |
| **의도적 비준수** | Netflix와 다르게 두었고, `decisions.md` 등에 근거가 있음 |
| **미준수·미커버** | Netflix 규칙인데 ZAMAK에 없거나 약함 |
| **해당 없음** | Netflix 납품·권리·플레이어·FN 제작 등 ZAMAK 제품 스코프 밖 |

한 조항에 하위 규칙이 섞이면 **주 판정**을 쓰고, 비고에 세부 갈래를 적는다.

이중 화자 `- … \| - …` 형식, 존댓말/반말(규칙 + opt-in 글로사리).

**의도적으로 Netflix와 다른 축**: 줄 길이 25자(16자 아님), 원본 이탤릭/스타일 태그
보존.

**제품 스코프 밖**: 폰트·FN 제작·다큐 권리·KNP 승인 제목 납품 절차.

## 조항별 상세

### I.1 약어 — 미준수·미커버

| | |
|---|---|
| Netflix | CD/DVD/DNA처럼 흔한 약어는 점 없이 |
| ZAMAK | 프롬프트·후처리에 약어 규칙 없음 |
| 근거 | — |

### I.2 글자 수 제한 — 의도적 비준수 (+ 0.5자 미커버)

| | |
|---|---|
| Netflix | 줄당 16자. 라틴·공백·부호 = 0.5자 |
| ZAMAK | `lineMaxChars: 25` (`languages.ts`). 모델에게만 가이드. **글자 가중치 0.5 없음** (전부 1자로 취급하는 CPS·길이 계산) |
| 근거 | `decisions.md` §2-6 — CPS_TARGET 10자/초 × ~2.5초 ≈ 25자. `docs/tuning/reading-speed.md` |

### I.3 인물·캐릭터 이름 — 미준수·미커버

| | |
|---|---|
| Netflix | 고유명 번역 금지(승인 번역 예외), 음차 가이드, 닉네임·약칭·역사인물 세칙 |
| ZAMAK | `cinematic_translation_philosophy_ko.txt` localization: 고유명사를 한국식으로 바꾸지 말 것. opt-in 글로사리(`extractCastSheet`)로 표기 일관성. Netflix 음차 가이드·약칭 금지·중간점 형식은 **미기술** |
| 근거 | `prompts/common/cinematic_translation_philosophy_ko.txt`, `cast_sheet_extraction.txt`, `decisions.md` §2-9 |

### I.4 연속성 — 준수(문자) / 미준수·미커버(연속 규칙)

| | |
|---|---|
| Netflix | `…`(U+2026). 연속 분할 자막에 말줄임표/대시 금지. 2초+ 멈춤·망설임·중단에만. 다음 자막 선두 `…` 금지 등 |
| ZAMAK | `enforceTextRules`가 `..`/`...` → `…` **코드 강제**. lean 프롬프트에는 연속성 규칙 없음 |
| 근거 | `app/lib/srt.ts` `enforceTextRules`, `translation-pipeline.md` §9.7 |

### I.5 다큐·비스크립트 — 해당 없음

화자 타이틀 1회, 클립 권리, 뉴스 티커 — 영상·권리 판단이 필요한 **납품 편집** 규칙.
ZAMAK는 업로드된 자막 텍스트를 번역한다.

### I.6 이중 화자 — 준수(형식) / 미준수·미커버(완결성)

| | |
|---|---|
| Netflix | `- ` + 한 줄 한 화자. 각 줄 완결 문장, 앞뒤 자막으로 미연결 |
| ZAMAK | `translation_rules_ko.txt` 규칙 2: `화자가 둘이면 - A \| - B`. 하이픈 형식은 유도. **완결 문장·타이밍 재배치**는 코드/프롬프트에 없음 |
| 근거 | `prompts/common/translation_rules_ko.txt` |

### I.7 폰트 — 해당 없음

플레이어/납품 패키지 속성. ZAMAK 출력은 SRT/VTT 등 텍스트.

### I.8 화면 글자·FN — 해당 없음

영상에서 FN을 새로 뽑는 워크플로가 없음. 원본 자막에 이미 있는 화면 글자 줄은 일반
대사와 같이 번역될 뿐, 큰따옴표·대사 분리·중복 삭제 규칙은 없음.

### I.9 외국어 대사 — 미준수·미커버

원작 자막 여부·작은따옴표 구분 등 미기술. 모델 판단에만 맡김.

### I.10 이탤릭 — 의도적 비준수

| | |
|---|---|
| Netflix | 한국어 자막에 이탤릭 사용 금지 |
| ZAMAK | 규칙 6: HTML/자막 태그 **위치·의미 유지** → 원본 `<i>` 등은 보존 유도. 제거 후처리 없음 (`TODO.md`에 태그 복원만 검토) |
| 근거 | `translation_rules_ko.txt` 규칙 6, `decisions.md` §2-8 스코프 아웃 |

원본에 이탤릭이 있으면 Netflix KO 납품 기준과 충돌할 수 있다. ZAMAK는 “원본 서식
보존”을 우선한다.

### I.11 줄 처리 — 준수(2줄) / 미준수·미커버(피라미드·예외)

| | |
|---|---|
| Netflix | 최대 2줄, 가능하면 1줄, 구두점·인용 예외, bottom-heavy |
| ZAMAK | 3줄+ → 2줄 병합 **코드 강제**. 줄바꿈 위치는 AI의 `\|`. 피라미드·구두점 3개 예외 미기술 |
| 근거 | `enforceTextRules`, `translation_rules_ko.txt` 규칙 2, §9.7 |

### I.12 숫자 — 미준수·미커버

24시간제 금지, 원화 미환산, 미터법 환산 등 없음. 규칙 3은 “숫자 대사도 대괄호 없이”
출력 형식용이지 Netflix I.12가 아님.

### I.13 문장부호 — 준수(줄 끝) / 미준수·미커버(나머지)

| | |
|---|---|
| Netflix | 줄 끝 `.`/`,` 금지. 한 자막 두 문장은 쉼표. `#`/`&`/`!`/`?!` 세칙 |
| ZAMAK | `trailingPunctuation: '.,'` → 줄 끝 `.`/`,` **코드 제거**. 쉼표로 잇기·`?!`·해시 규칙은 없음 |
| 근거 | `languages.ts`, `enforceTextRules`, §9.7 |

### I.14 따옴표 — 미준수·미커버

큰따옴표(FN/타이틀)·작은따옴표(인용·작품명)·보이스오버 무따옴표·다중 자막 따옴표
규칙 없음.

### I.15 읽기 속도 — 준수(성인) / 미준수·미커버(아동)

| | |
|---|---|
| Netflix | 성인 ≤12 CPS, 아동 ≤9 CPS |
| ZAMAK | ko `reading.hardMax: 12`, `target: 10`. `adjustSubtitleTiming`이 hardMax 초과 블록만 늘림. **아동 콘텐츠 분기 없음** |
| 근거 | `languages.ts`, `docs/tuning/reading-speed.md`, `decisions.md` §2-5, §9.5 |

참고: CPS 조정은 **표시 시간을 늘리는** 쪽이지, 번역문을 짧게 만드는 Netflix식
“쓰기 예산”은 아님 (`TODO.md` CPS 기반 길이 예산).

### I.16 반복 — 미준수·미커버

philosophy compression: 불필요한 반복 생략 **가능**이라고만 함. “같은 자막 안 반복
미번역 / 연속 2회는 한 번만”은 명시되지 않음.

### I.17 노래 — 해당 없음(권리) + 미준수·미커버(형식)

| | |
|---|---|
| 권리·플롯 판정 | 해당 없음 |
| `♪`만 있는 블록 | `hasTranslatableText`가 번역 재시도에서 제외 — Netflix “가사 자막” 규칙과는 별개 |
| 가사 부호·따옴표·말줄임 | 미커버 |

### I.18 제목 — 미준수·미커버 (부분)

| | |
|---|---|
| Netflix | KNP 승인 제목, 일치 시 미자막, 줄 한도 예외 등 |
| ZAMAK | enrich가 TMDB/그라운딩 **한국어 제목**(없으면 음차)을 UI·메타에 씀. 메인 타이틀 **자막 이벤트 생성**·KNP·에피소드 제목 규칙은 없음 |
| 근거 | `enrichMovie.ts` (`needsTransliteration` 등) |

### I.19 말투 — 준수

| | |
|---|---|
| Netflix | 맥락·관계·시대로 존대 결정. 성별·나이만으로 결정하지 말 것 |
| ZAMAK | 규칙 5: 호칭·나이·직위·친밀도. philosophy `character_voice`. opt-in `<speech_relations>`. 성별 단독 결정 금지는 명시적 “Don’t” 목록은 없으나, 관찰 근거(호칭 등) 중심으로 맞춤 |
| 근거 | `translation_rules_ko.txt`, `cinematic_translation_philosophy_ko.txt`, `cast_sheet_formality_task.txt`, §2-C |

주의: 글로사리 토글 **기본 OFF** → 끈 상태에서는 청크 단위 규칙 5만으로 말투가
흔들릴 수 있음 (`decisions.md` §2-9).

### I.20 특별 지침 — 혼합

| 하위 | 판정 | 비고 |
|---|---|---|
| 톤·레지스터 등가 | 준수 | philosophy emotion/tone, localization |
| 검열 금지·욕설 충실 | 미준수·미커버 | 명시 조항 없음 |
| 플롯 대사 > 배경 | 해당 없음에 가깝음 | 입력 자막에 이미 선별된 전제 |
| 브랜드 처리 | 미준수·미커버 | 없음 |
| 욕설 등가 세기 | 미준수·미커버 | “과장 금지”만 인접 (`emotion_and_tone`) |

### I.21 참고 — 해당 없음

외부 URL·벤더 포털. 제품 동작과 무관. 번역본에 링크만 보존.

## 해석 메모

1. ZAMAK 목표는 **Netflix 납품 준수 엔진이 아니라** “후편집용 고품질 초벌”
   (`cinematic_translation_philosophy_ko.txt`). 이 검토의 “미준수”는 곧 버그가
   아니라 **아직 제품 요구로 끌어올리지 않은 Netflix 규칙**이다.
2. lean 프롬프트(2026-07-28) 이후 기계 규칙은 **코드 강제**에 더 의존한다. 예전에
   프롬프트에 있던 말줄임·마침표 문구가 빠져 있어도 §9.7이 커버하면 **준수**로 본다.
3. 파이프라인·상수가 바뀌면 이 표의 판정만 갱신하고, 번역본
   (`netflix-korean-subtitles.md`)은 원문 변경 시에만 손본다.
