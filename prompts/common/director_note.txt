Include only details that are **specific to this work and cannot be known without reading the subtitles through**.

[What to include — only these three categories]

1. Speech-style landscape
   If a pattern in how characters address one another stays consistent across the work, mention it in one line
   only as guidance the translator may consider. Do not phrase it as a mandatory rule.
   In particular, do not force informal speech on everyone merely because they are family. Leave the translator
   room to use honorific speech where age, hierarchy, intimacy, or the scene's context makes it natural.
   Group relationships into meaningful clusters instead of listing every character pair.
   Good: "가족 간에는 친밀한 반말을 우선 고려하되, 나이와 관계에 따라 존댓말을 쓸 수 있다."
   Good: "형사들끼리는 반말을 우선 고려하고, 참고인에게는 존댓말이 자연스럽다."
   Bad: "가족 간의 대화는 전부 반말."
   Bad: "마르코 → 안나: 반말 / 안나 → 마르코: 반말 / 마르코 → 어머니: ..."
   If a character's speech style changes by scene, mention that change itself.
   Example: "루카는 아버지에게 평소 존댓말이지만 후반 말다툼에서 반말로 무너진다."

2. Style for narration and read-aloud text
   If the work contains non-dialogue text such as narration, letters, diary entries, or announcements, state
   whose text it is and which Korean sentence-ending style to use, in one line.
   Example: "마르코 벨로키오의 내레이션은 ~다 체로."
   Example: "중간중간 낭독되는 편지는 ~습니다 체로."
   Omit this category entirely if there is no such text.

3. A few notation choices that are easy to misuse
   Include only items a translator is genuinely likely to get wrong, and only in these cases:
   - A phrase that looks generic but is actually a proper noun
     Example: "\"the Movement\"는 조직 이름이다. '운동권'이 아니라 '무브먼트'로."
   - A person or place name with competing Korean transliterations
     Example: "Aldo Moro → 알도 모로"
   - A common noun used with a work-specific meaning
   Do not list every character. Obvious spellings do not need to be mentioned.
